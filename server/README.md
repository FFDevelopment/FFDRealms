# FFDRealms development backend

The v0.4.x backend provides development account services, multiplayer presence, and admin analytics.

Environment variables:
- `FFDREALMS_ADMIN_KEY` — admin dashboard secret
- `FFDREALMS_PORT` — server port
- `FFDREALMS_HOST` — bind address
- `FFDREALMS_DB` — alternate SQLite path

Do not expose the development backend directly to the public internet.

# Asset notes — 0.2.3

World, character, creature and prop meshes remain the project's original procedural Godot geometry. No RuneScape/Jagex maps, characters, models, artwork, names or interface assets are bundled. The concept screenshot shown previously is not a runtime asset or a screenshot of this release.

## New world textures

`assets/textures/world/` contains 18 original, deterministic 512×512 neutral albedo maps and 18 OpenGL-style normal maps, along with portable Godot importer settings and a SHA-256 manifest. No photographs, external texture packs, font files, downloaded models or paid generation service were used. The new texture family names are grass, earth, path, cobble, stone, masonry, plaster, shingles, timber, planks, bark, leaves, ore, canvas, metal, moss, fur and water.

`tools/bake_world_textures.py` is the reproducible authoring source. It requires Python, Pillow and NumPy only when regenerating the textures; the player only needs Godot. It uses periodic noise, wrapped strokes, irregular paving cells, wood grain, cloth weave, mineral seams and height-derived surface normals. It does not access the network or user saves.

Godot imports the opaque RGB PNGs with mipmaps and lossless texture storage. World material parameters provide existing object tints and restrained roughness/specular response. Creature mapping is object-local; no body textures are applied to eyes, glow indicators or combat warning sectors. Local coloring does not propagate to the wardrobe's separate material instances.

## Retained art

Characters still have the original 128×128 runtime-generated neutral fabric maps for cotton, linen, knit, denim, slacks, canvas, leather and suede, with separate per-character dyes. Jeans/slacks mesh details and all clothing settings are unchanged.

Creature silhouettes remain lightweight prototypes. The northern courtyard is open-air and the houses remain exterior-only decorative buildings. No new geometry or collision boundary was added by this texture pass. Default runtime fonts are used; no font binaries are distributed.

The existing third-party development grammar and its license remain under `tests/vendor/gdtoolkit/`. It is not a runtime art dependency.

The baked texture swatches were inspected; the game was not rendered here. Refer to `docs/TESTING.md` for the distinction between executed source/asset tests and pending native/rendered tests.


## 0.3.0 terrain assets

The heightfield, ground blend/tint masks and relief map are original deterministic procedural work generated by the included `tools/bake_terrain.py`, using the existing original texture families. No stock models, paid services or generated reference image are needed at runtime. `data/terrain/manifest.json` records sample dimensions and checksums.

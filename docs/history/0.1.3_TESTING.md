indenter. It does not validate Godot constants, types, imports, compiled shaders or
runtime behavior. The source validator checks guards and a reference navigation
grid; it does not execute GDScript gameplay.

## Run on the test PC

Extract the full new project and run `Run Tests.bat` using your installed Godot
executable. It runs native project import, then `tests/test_runner.gd`, then
`tests/smoke_runner.gd`. Output goes to `test-results.log`. Error output and nonzero
exit codes fail the launcher. The scene smoke check is headless; it is not a visual
test or a guarantee of rendered quality.

Test save writes remain isolated under `user://test_profiles`. Normal three-slot
profiles are never intentionally overwritten by these test scripts.

Optional local source checks:

```sh
python tests/check_project.py
# Requires installed Python lark + regex, not needed to play:
python tests/check_grammar.py
```

## Added native regression cases (included, not run here)

- One click plus prolonged idle gives one log, ore or fish and exactly one XP award.
- Early click spam, target switching during work, duplicate completion callbacks,
  cancellation, resource replenishment and enemy respawn cannot schedule rewards.
- Further progress requires a new post-completion interaction request.
- Cooking and smithing do not continue consuming remaining ingredients when idle.
- Fishing works from all four sides, corners and non-grid-aligned dry positions.
- Distant clicks approach the corresponding reachable bank without crossing water;
  blocked shore routes, nonfinite/out-of-pond coordinates and bad payload types fail.
- Bait transactions, full bag/final bait exchange, bank transfers and save round-trips.
- One attack causes one hit; idle does not attack/counterattack or earn kill XP.
- NPC retaliation continues between clicks, cannot be reset with cancel, and stops
  when the player leaves range; death and rewards remain bounded.
- Saving during an action does not serialize a future automatic catch.
- Scene initialization retains lighting, shows the rod/line/float per cast, hides
  them after completion with spare bait left, and captures busy input as ineligible.
